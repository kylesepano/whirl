# Recruiter demo

Run `npm.cmd ci` and `npm.cmd run dev`, then open **http://127.0.0.1:5173/**.

1. Choose **Quick Play** and spin. Try five rounds to see the score, explanations, sources, and session results. Reload during a round or after feedback to verify that state can be recovered.
2. On a WHERE question, pan and zoom the bundled world map. Select a country for a country question, or place a pin for a city or landmark question.
3. Follow the [local admin setup](README.md#set-up-the-local-admin), then visit `/login` directly. Search the Question Bank, create or edit a question, and preview it. Save it for review, then publish after checking the source.

Players need no credentials. Admin credentials are set per installation.
