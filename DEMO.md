# Recruiter demo

Run `npm.cmd ci` and `npm.cmd run dev`, then open **http://127.0.0.1:5173/**.

1. Select **Play Roulette**, choose **Quick Play**, and spin. Try five rounds to see the score, explanations, sources, and session report. Reload during a round or after feedback to verify that state can be recovered.
2. Open **My progress** for category metrics, practice suggestions, and recent sessions. **Achievements** update from submitted answers. Completed ranked games appear on the leaderboard.
3. On a WHERE question, pan and zoom the bundled world map. Click to place a pin, drag it to adjust, or use coordinate entry. Submit to see the distance line and points.
4. Follow the [local admin setup](README.md#set-up-the-local-admin), then choose **Admin sign in → Questions**. Create or edit a variant, preview it, and save it for review. Publish after verifying the source. Try deleting a test question and confirming its removal.

Players need no credentials. Admin credentials are set per installation.
