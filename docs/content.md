# Question sourcing and media

The starter content is generated by `node scripts/seed.mjs` into the tracked seed migration. Each published variant includes its own topic, wording, answer data, explanation, source title and URL, and verification timestamp. Sources include NASA mission and photo archives, UNESCO World Heritage listings, the USGS, NOAA/NWS, the Smithsonian, Darwin Online, CERN, and the U.S. National Archives. Source links are available after scoring.

Follow [NASA's media guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/). WHIRL makes no claim of NASA affiliation or endorsement. Other images need individual rights checks. Add the creator, license, source URL, and, for portraits, subject and medium. Use opaque filenames and check photos for visible names or answer text.

WHERE maps use MapLibre GL JS with bundled Natural Earth 1:110m country and place data. The map displays attribution and needs no tile service or key. Natural Earth shows de facto boundaries. Run `node scripts/map-data.mjs` to regenerate the two GeoJSON files from the pinned upstream release. ## Import review candidates

Set `WHIRL_IMPORT_CONTACT` to your email or project URL for the Wikimedia request header. Set `WHIRL_DATABASE_URL` to a PostgreSQL connection string with migration-owner write access. The script respects request limits, retries transient failures, locks each import source, and commits the cursor in the same transaction as its batch. Re-running a class resumes from its latest cursor. A unique Wikidata item slug and unique prompt prevent duplicated publication candidates.

```powershell
npm.cmd run import -- --dry-run --limit 5
npm.cmd run import -- --class Q33506 --limit 1000
```

Supported classes are museums (`Q33506`), schools (`Q3914`), businesses (`Q4830453`), libraries (`Q7075`), cities (`Q515`), observatories (`Q62832`), zoos (`Q43501`), and hospitals (`Q16917`). The importer reads English-labeled, referenced Gregorian inception claims from [Wikidata Query Service](https://www.mediawiki.org/wiki/Wikidata_Query_Service/User_Manual). Wikidata structured data is [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). The importer creates WHEN drafts. Distinct candidates may require several batches and classes.

A Wikidata reference is a lead for verification. In **Admin → Review queue**, inspect the cited document, confirm the intended event and date, revise the explanation and timeline range, then validate and publish. Review spelling, subject classification, and entities that duplicate existing topics. WHO, WHERE, WHAT, WHY, and HOW variants need separately sourced material and remain editorial work.
